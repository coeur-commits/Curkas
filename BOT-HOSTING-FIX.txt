CURKAS MD - Bot-Hosting.net fix

This version intentionally does NOT include package-lock.json.
The previous lockfile forced Baileys' libsignal dependency through Git/SSH,
which is blocked by hosts that disable Git dependencies.

package.json now explicitly uses:
  libsignal: ^6.0.0
and npm override:
  libsignal: ^6.0.0

On Bot-Hosting.net, reinstall dependencies from package.json (do not upload
an old package-lock.json).
